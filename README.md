# 支教管理小程序 · 雾霾蓝版

> 一款面向大学生支教志愿者的微信小程序原型，专注于支教项目的全流程管理——从档期发布、岗位认领、教案提交到知识沉淀。

## 开发工作流

本项目已经从静态 HTML 原型推进为 `uni-app + Vue 3 + TypeScript` 微信小程序工程。协作时请注意区分“源码目录”和“微信预览目录”：

- 只修改源码：`src/`、`cloudfunctions/`、项目配置文件与文档。
- 不要手动修改编译产物：`dist/dev/mp-weixin`、`dist/build/mp-weixin`。
- 微信开发者工具导入目录：`D:\teaching-assistant-miniapp\dist\dev\mp-weixin`。

开发预览时，在项目根目录运行：

```bash
cd /d D:\teaching-assistant-miniapp
npm.cmd run dev:mp-weixin
```

提交或交付前，至少运行：

```bash
npm.cmd run type-check
npm.cmd run build:mp-weixin
```

如果微信开发者工具里看到的效果和源码不一致，优先检查 `npm.cmd run dev:mp-weixin` 是否仍在运行，以及打开的是否是 `dist/dev/mp-weixin`，而不是直接编辑 `dist` 里的文件。

## 📱 项目概述

本项目是「支教管理小程序」的高保真原型，采用雾霾蓝设计风格，旨在解决支教活动中常见的**信息不对称、流程不规范、资源难复用**三大痛点。

### 核心价值

- **信息透明**：支教档期、岗位需求一目了然
- **流程规范**：认领→提交教案→审核→立项→招募，环环相扣
- **知识沉淀**：优秀教案、PPT、方案可被复用和传承

## 🎯 功能模块

### 1. 日历首页

按周展示支教课程安排，支持快速浏览：

- 📍 课程主题与地点（如「趣味科普：地球的呼吸」）
- 🕐 时间安排（如 7月5日 周六 14:00-16:00）
- 🟢 项目状态标识：
  - 🟢 招募中：正在招募助教、PPT 等岗位
  - ⚡ 待认领：等待支协成员抢占档期
- 👥 已认领岗位人员展示

### 2. 项目详情

点击课程卡片进入详情页，包含：

- **教案大纲**：课程目标、教学流程概述
- **项目负责人**：认领该档期的主讲人
- **岗位认领**：
  - 👨‍🏫 主讲（1人）
  - 📱 PPT（1人）
  - 👨‍🏫 助教（可多人）
  - 📷 摄影（1人）
  - 📋 场务（1人）
- 一键认领 + 实时名额更新

### 3. 资料库

支教资源的知识管理中心：

- 🔍 全文搜索（教案、PPT、方案）
- 📂 分类筛选：科普 / 人文 / 艺术
- 🏆 精品标记：优秀教案打标「精选」
- 📝 遗珠标记：未中标但有价值的方案标记「未中标遗珠」
- 字数/页数统计 + 更新时间

### 4. 个人中心

志愿者的个人工作台：

- 👤 个人信息：姓名、角色（支协成员/项目负责人/管理员）
- 📊 数据统计：参与项目数、志愿时长、带队次数
- 📋 我的项目：查看已认领的课程及状态
- 💰 报销进度追踪
- 📁 我的资料收藏

**管理员专属功能**：
- 📅 档期发布工具
- 📝 教案审核台
- 👥 支协成员管理
- 💳 报销审批台

### 5. 认领 + 教案提交

支协成员抢占档期后的核心流程：

- ✅ 认领成功提示（你是第一个抢占者）
- ⏰ 24小时限时提交教案
- 📎 支持上传 Word (.docx) / PDF，最大 20MB
- 📄 PDF 预览功能
- 🛠️ 设置辅助岗位人数（±调整）

### 6. 教案审核台（管理员）

管理员审核教案的核心界面：

- 📋 待审核教案列表
- 👤 提交人信息
- 📄 教案文件预览
- 👥 辅助岗位配置展示
- ✅ 通过 → 项目立项，进入「招募中」状态
- ❌ 驳回 → 档期释放，变回「待认领」

## 🎨 设计规范

### 风格定位

- **主色调**：雾霾蓝（#5B8FB9 柔和蓝）
- **设计语言**：清新、简洁、适合学生群体
- **交互特点**：
  - iOS 风格顶部状态栏模拟
  - 底部 Tab 导航（日历 / 资料库 / 我的）
  - 卡片式布局，信息层次清晰
  - 状态标签颜色区分（绿=招募中，橙=待认领）

### 原型说明

本原型为**高保真 HTML 原型**，可直接在浏览器中查看完整的交互流程和视觉效果。适合作为：

- 产品需求文档（PRD）的视觉补充
- 开发团队的 UI 参考
- 用户调研的可交互 Demo
