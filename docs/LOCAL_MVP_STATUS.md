# 支教管理小程序：本地 H5 MVP 完成状态

更新日期：2026-07-10

## 已完成的本地业务闭环

- 用户资料维护与本地身份切换。
- 日历按周、按日查看支教档期。
- 管理员发布、编辑、筛选和取消档期。
- 负责人认领、教案提交、管理员审核、驳回重交。
- 教案历史版本保存、审核记录与 PDF/Word/PPT 统一预览。
- 辅助岗位动态数量、认领、十分钟内取消、管理员移除成员。
- 项目完成申请、逐成员时长填写、管理员确认、时长入账。
- 志愿时长明细和带编号的服务证明。
- 资料库搜索、分类、收藏、自动沉淀和文档预览。
- 站内通知未读、已读和业务页面跳转。
- 报销提交、管理员审核、驳回、通过和标记已打款。
- 本地 API 自动化测试、TypeScript 类型检查和 H5 构建。

## 不阻塞本地 MVP 的上线阶段任务

- 微信登录与真实 OpenID 身份体系。
- 正式服务器数据库、事务、权限中间件和部署。
- 真实文件上传、对象存储、临时签名 URL 和 `wx.openDocument`。
- 微信订阅消息和合法域名配置。
- 真机安全区、导航栏、页面栈及性能适配。
- 生产数据迁移、备份、监控和审计。

## 可选增强项

- 运营数据看板。
- 服务证明导出 PDF 或盖章文件。
- 资料评论、评分与经验分享。
- 多组织、多校区和多基地管理。

本文件中的“已完成”指本地 H5 与 mock API 环境已形成可测试闭环；上线阶段任务需在服务器和微信环境确定后实施。
